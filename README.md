# 제주시 임야 재배임산물 추천 (웹)

제주시산림조합 산림경영지도용 도구입니다. 지번을 넣으면 입지·기후·토양·규제를 겹쳐 재배 임산물 1~3순위와 인허가 검토를 보여줍니다.

- 주소: https://jeju-nfcf.github.io/
- 휴대폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다. 한 번 연 뒤에는 인터넷 없이도 열립니다.
- 열 때마다 새 판이 있는지 확인하고, 있으면 받아서 '새로고침' 안내를 띄웁니다.
- 자료: 연속지적도 2026.9.8, 토지·임야대장 면적 2026.9.4(변동분 2026.10.7까지) 등. 자세한 출처와 한계는 페이지의 '자료·한계' 탭을 보세요.

이 저장소의 파일은 생성물입니다. 원본과 생성 스크립트(`tools/build_web.py`)는 별도 저장소에서 관리합니다.
